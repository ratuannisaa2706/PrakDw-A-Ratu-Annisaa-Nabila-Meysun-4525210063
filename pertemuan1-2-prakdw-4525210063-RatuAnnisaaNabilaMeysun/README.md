# Profil IMATIKA

Halaman web statis sederhana yang saya buat menggunakan HTML untuk memperkenalkan **IMATIKA (Ikatan Mahasiswa Teknik Informatika)**. Halaman ini memuat identitas organisasi, program keahlian, alur pendaftaran, serta kontak dan media sosial.

## Deskripsi Singkat

Tugas ini saya kerjakan untuk melatih dasar-dasar HTML, yaitu struktur dokumen, heading, paragraf, gambar, list, tautan, dan navigasi antarbagian dalam satu halaman.

## File

| File | Keterangan |
|------|------------|
| `index.html` | Halaman Kontak dan Media Sosial |
| `contohprogram.html` | Halaman Profil Mahasiswa (latihan tag teks dan karakter khusus) |
| `TugasPrak.html` | Halaman utama Profil IMATIKA |
| `img/imatika.jpg` | Logo IMATIKA |

## Struktur Halaman (TugasPrak.html)

1. **Header**: judul "IMATIKA" (`<h1>`) beserta slogan organisasi.
2. **Navigasi**: tautan anchor (`<nav>` dan `<a href="#...">`) menuju tiap bagian halaman.
3. **Identitas Organisasi**: logo (`<img>`), nama organisasi, alamat, dan akreditasi dalam *unordered list* (`<ul>`).
4. **Program Keahlian**: daftar program berdasarkan peminat terbanyak dengan *ordered list* (`<ol>`): AI, NCS, Data Science, dan Software Engineering.
5. **Alur Pendaftaran**: contoh data pendaftar (nama, umur, hobi, cita-cita) dalam bentuk *ordered list*.
6. **Kontak & Media Sosial**: tautan Instagram (`target="_blank"` agar terbuka di tab baru) dan email (`mailto:`).
7. **Footer**: hak cipta dan email kontak memakai tag `<small>`.

## Tag HTML yang Digunakan

| Tag | Fungsi |
|-----|--------|
| `<!DOCTYPE html>` | Menentukan dokumen HTML5 |
| `<html lang="id">` | Elemen root berbahasa Indonesia |
| `<head>`, `<meta>`, `<title>` | Informasi dokumen, encoding, dan judul tab |
| `<h1>` - `<h3>` | Judul dan subjudul |
| `<p>`, `<br>` | Paragraf dan baris baru |
| `<nav>`, `<a>` | Navigasi dan tautan |
| `<img>` | Menampilkan logo |
| `<ul>`, `<ol>`, `<li>` | Daftar tidak berurutan dan berurutan |
| `<b>`, `<strong>`, `<em>`, `<u>`, `<small>` | Format teks |
| `<hr>` | Garis pemisah antarbagian |
